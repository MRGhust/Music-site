# هم‌آوا · Hamava

یک فضای فارسی برای گوش‌دادن همزمان به موسیقی با دوستان. رابط راست‌به‌چپ، تم تیره و سبز نعنایی، طراحی واکنش‌گرا و انیمیشن صفحهٔ موسیقی.

## امکانات

- ساخت روم و دعوت با لینک یا کد
- آپلود MP3، WAV، OGG، M4A و FLAC تا ۵۰ مگابایت برای هر فایل
- پخش، توقف، انتخاب آهنگ و جابه‌جایی زمان مشترک با Socket.IO
- تخمین اختلاف ساعت دستگاه با سرور و اصلاح اختلاف پخش هر دو ثانیه
- صف آهنگ، حذف توسط میزبان و تکرار صف
- چت روم و فهرست شنونده‌ها
- تنظیم مجوز کنترل و آپلود مهمان‌ها، غیرفعال‌کردن چت و رمز ورود
- ذخیرهٔ دائمی اطلاعات در SQLite و فایل‌های صوتی روی دیسک
- صدای مستقل هر دستگاه و پشتیبانی از تنظیم کاهش حرکت

## اجرای محلی

Node.js 24 لازم است.

```sh
npm ci
npm run dev
```

سایت روی `http://localhost:3000` در دسترس است. در دو مرورگر جداگانه روم را بسازید و با لینک دعوت به آن بپیوندید. هر شنونده برای اجازهٔ پخش مرورگر باید یک‌بار صدا را فعال کند.

## اجرای تولید

```sh
npm ci
npm run build
npm start
```

یا با Docker:

```sh
docker compose up --build -d
```

روی یک سرور با دیسک دائمی اجرا کنید؛ دامنه و HTTPS را با reverse proxy مانند Caddy به پورت 3000 متصل کنید. WebSocket باید در پراکسی فعال باشد. حجم درخواست پراکسی را حداقل ۵۱ مگابایت بگذارید. فایل‌ها و پایگاه داده در `data/` هستند؛ از این پوشه بکاپ بگیرید. `PORT` و `DATA_DIR` قابل تنظیم‌اند. Docker از volume دائمی استفاده می‌کند.

## بررسی

با سرور روشن:

```sh
npm test
```

تست یکپارچه، ساخت و ورود روم، آپلود صوت، هماهنگی دو اتصال، جابه‌جایی پخش، گفت‌وگو، دسترسی میزبان، رمز و درخواست بخشی از فایل صوتی را بررسی می‌کند.

## نکات اجرایی

این نسخه برای اجرا روی یک نمونهٔ سرور طراحی شده است. برای چند نمونه، هماهنگی Socket.IO و ذخیره‌سازی مشترک لازم است. روم‌ها دعوتی‌اند؛ کد روم قابل کشف در فهرست عمومی نیست. برای محدودکردن ورود، رمز تعیین کنید. رمز جدید نشست‌های فعلی را خارج نمی‌کند. نشست میزبان در مرورگر ذخیره می‌شود و ۳۰ روز معتبر است؛ با پاک‌کردن اطلاعات مرورگر یا خروج، دسترسی میزبان را از دست می‌دهید. فایل صوتی فقط با نشست معتبر همان روم دریافت می‌شود. لینک دعوت به‌تنهایی مجوز مدیریت نمی‌دهد.

همزمانی تابع شبکه و دستگاه است و دقت نمونه‌به‌نمونهٔ صوت تضمین نمی‌شود. فایل‌ها به فرمت دیگری تبدیل نمی‌شوند؛ پشتیبانی هر فرمت به مرورگر بستگی دارد. تنها فایل‌هایی را آپلود کنید که حق اشتراک‌گذاری آن‌ها را دارید. برای انتشار عمومی بزرگ، سهمیهٔ ذخیره‌سازی، مدیریت کاربران، محدودیت ساخت روم و ابزار حذف داده اضافه کنید.

## فناوری‌ها

React، Vite، Express، Socket.IO، SQLite و Lucide. قلم فارسی Vazirmatn از Google Fonts دریافت می‌شود و در صورت عدم دسترسی از قلم دستگاه استفاده می‌کند.
